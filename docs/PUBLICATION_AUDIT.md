# 开源发布检查

检查日期：2026-10-25。对象为 CraftBridge v0.2.0 源码 ZIP 的全部条目、文本内容，以及 PNG / ICO 图标的元数据。

## 检查结果

- 原源码包只有 25 个源码、测试、文档和图标文件；未包含 `build/`、`dist/`、Git 历史、环境配置、日志、调试符号、游戏数据或账号文件。
- 未发现真实本机用户目录、个人姓名、邮箱、访问令牌、私钥或密码等凭据。
- `C:\UI-fixture*`、`C:\UI-target*` 等是虚构的界面状态测试字符串；`C:/file`、`../escape.jar` 等是验证路径防护的测试输入。它们不是开发者的真实目录，也不是需要执行的路径。
- 源码包中的 ZIP 条目均为相对路径，没有 ZIP 注释。PNG / ICO 不含文本或 EXIF / XMP 元数据、额外尾部载荷；ICO 内部为单个 PNG 图像。
- 本项目没有捆绑第三方库、启动器代码或第三方图标、字体文件。上游参考项目及其许可证列于 [第三方说明](THIRD_PARTY.md)。

本次主要缺项是根目录没有许可证，已新增标准 MIT `LICENSE`，使用公开项目署名 `CraftBridge contributors`，未写入个人姓名或邮箱。README 和程序集版权信息同步更新；构建时会把许可证复制到发行目录。

## 发布范围

公开源码包按明确清单生成，只包含根目录说明、许可证、构建脚本、Git 规则，以及 `src/`、`tests/`、`docs/`、`assets/`。本机 `build/` 中的测试结果、诊断程序、临时路径文件和构造迁移包不属于公开源码包。

`.gitignore` 已补充排除构建输出、压缩包、调试符号、本地 IDE 配置、环境变量文件、密钥文件、游戏目录及本工具的临时和备份目录。

向 GitHub 上传时使用经过检查的 MIT 源码包解压内容。根目录应直接包含 `README.md`、`LICENSE`、`build.ps1` 和源码目录，不需要上传本机工作区的构建与诊断文件。

检查结论仅针对本次源码包及已检查内容，不涵盖后续手动加入的文件、其他目录或已有远程 Git 历史。
